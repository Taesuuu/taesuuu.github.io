CASE_01 / uCMP

리포트 성능, 데이터 정합성 문제 해결

쿼리 최적화로 30% 빠르게, 방어 로직으로 장애 재발 0건
PROBLEM
리포트 생성 중 타임아웃 발생, 원인 불명의 메트릭 누락 장애도 월 1~2회 재발
ANALYSIS
Codex, GPT에 수집 로직을 전달해 가설 도출 후 직접 DB 쿼리로 검증 — 반복문 안에서 SQL을 매번 개별 호출하는 패턴 확인
ACTION
반복문 진입 전 필요한 데이터를 일괄 조회 후 Map으로 캐싱, 반복문 안에서는 메모리 조회만 수행하도록 리팩토링. 기존 로직과 병행 운영하며 AI로 결과 비교 검증한 뒤 전환해 롤백 리스크 최소화
RESULTVERIFIED
리포트 속도 약 30% 개선
PRINCIPLE
AI가 제시하는 원인과 해법은 가설로 취급, 직접 DB 쿼리와 로그로 검증한 뒤에만 반영 (이후 다른 리팩토링에도 동일 적용)
+ ADDITIONAL
같은 조사 과정에서 OCI API가 메트릭을 간헐적으로 누락하는 것도 함께 발견, Agent에 재조회 방어 로직을 추가해 메트릭 누락 장애 재발 0건 달성
CASE_02 / RAG ChatBot

Milvus RAG 기반 AI QA ChatBot 설계

벡터DB 구축부터 다중 모델 선택까지, AI 서비스 데이터 흐름 전체를 처음부터 설계

사내 문서를 Milvus 벡터DB에 임베딩으로 저장, GPT·Gemini 중 선택 가능한 답변 생성 챗봇을 설계부터 구현까지 담당했습니다.

학습 범위 밖 질문은 OpenAI API 직접 연동 폴백 로직, 사용자별 대화 이력 기반 개인화를 구현했습니다. 임베딩 저장부터 검색, 다중 모델 선택, 예외 처리, 개인화까지 AI 서비스의 데이터 흐름 전체를 처음부터 설계했습니다. 자회사에서 병행 개발한 유사 서비스보다 효율적인 구성으로 채택되어, 이후 운영은 외부 업체로 이관됐습니다.
